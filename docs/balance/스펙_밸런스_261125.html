픽셀 오디세이 스펙 밸런스

레벨·장비·강화·계승·품질·잠재·반지·쁘띠·특성 등 모든 스펙업 수단이 장(챕터)마다 보스 딜·사냥 딜·생존을 얼마나 올리는지, 그리고 그 결과 보스가 얼마나 걸리는지 정리했다. 모든 숫자는 정식 index.html 의 calcStats·presetGear·spawnBoss 를 그대로 불러 계산했다.

핵심 결론

위에서부터 영향이 큰 순서. 1·2번은 후반 콘텐츠 전체를 막는 구조 문제다.

심각11장부터 보스가 과하게 단단하다

기준 장비(레어·잠재 없음)로 10장 보스 72초 → 11장 8분 → 20장 55분 → 30장 1시간 37분. 끝까지 최강 세팅을 해도 20장 3분 반, 30장 7분. 설계 목표는 40~78초.

심각장 난이도 모델이 실제 상한을 모른다

몹·보스는 "장 n 의 기대 캐릭터 = 레벨 8n−1, 계승 최대 5회" 로 맞춰졌는데 실제는 레벨 150 상한, 계승 2회 상한. 30장에서 실제로 가능한 딜이 기대치의 51%.

주의치명타 확률이 15장 무렵 100% 로 꽉 찬다

하의의 기본 능력치가 치명타 확률이라 장비만으로 100%. 그 뒤로 치명타 확률 잠재·장비 옵션·하의 강화는 사실상 0. 30장에선 99%p 가 버려진다.

주의견갑·신발 강화는 거의 의미 없다

강화 +1 당 보스 피해 +0.1%, 방어력 무시 +0%. 같은 비용으로 무기 강화는 딜 +1.2~5%.

주의계승 1번 = 다른 모든 수단을 압도

계승 +1 이 딜 +23~233%, 생존 +47~406%. 그런데 10·20장 보스로만 얻고 2번이 끝이라, 계승 몫까지 기대한 후반 난이도와 어긋난다.

참고19장부터 레벨업은 스펙에 0

레벨 150 상한에 19장(기대 151)에서 닿는다. 그 뒤 성장은 장비뿐이고, 경험치 획득량 잠재도 쓸모가 없어진다.

심각권장 전투력은 15장부터 못 만든다

레전드·최상급으로도 15장 권장의 95%, 20장 40%, 30장 22%. 권장 전투력이 기대 캐릭터(레벨 239·계승 5회)로 계산되기 때문.

주의Z(평타) 특성 하나가 나머지를 압도

딜의 75~88% 가 평타라 Z 특성 15단계가 딜 +75~123%. 다음으로 센 특성은 직업마다 +14~28%. 사실상 "Z 먼저"가 정답이라 선택의 재미가 없다.

주의전투력 숫자가 각성·보스 피해를 거의 못 본다

Lv75 각성(딜 +31%)은 전투력 +0.9%, 보스 피해 잠재(딜 +13%)는 +2%. 잠재 전반도 실제의 65~75% 만 잡힌다.

참고후반 최대 성장은 잠재

같은 레전드 장비에서 잠재 평균 세트 ×3.9, 최대 세트 ×6.7. 등급(+34~49%)·계승(+38%)보다 훨씬 크다.

특성은 두 종류. 기존형: 1단계 큰 효과 → 3단계 [변경] → 4·5·7·9단계 피해 +15·15·20·25% → 6단계 재사용 −20% → 8단계 치명타 +4% → 10단계 [각성] → 11~14단계 +6%씩 → 15단계 +25%. 신규형: 단계마다 피해 +5%·재사용 −1%, 10단계 재사용 −15% 더, 15단계 피해 +25% 더. 비용은 1~5단계 1점, 6~10단계 2점, 11~15단계 3점(15단계까지 30점). 레벨 150 에서 받는 포인트는 149 라 여섯 개를 다 채우지 못한다(180점 필요).

딜 효과 = 그 스킬의 딜 비중 × (피해 배율 ÷ 재사용 배율 − 1). 딜 비중은 허수아비 90초 실측. 측정 안 됨 = 자동 조작에서 맞지 않은 스킬(덫·은신·위치 조건) — 실제로는 0 이 아닐 수 있다. [변경]·[각성]의 추가 타격·화상·독·표식은 계산에 안 넣어서 기존형 X·C 는 실제로 이보다 크다.

고칠 방법 (우선순위)

  1. 11~30장 보스 체력을 실제 상한 기준으로 다시 맞추기목표를 "최강 세팅 1분, 기준 세팅 3~5분" 처럼 정하고 보스별 체력을 낮춘다. 지금 실측으로 20장은 약 1/3, 30장은 약 1/5~1/6 로 낮춰야 최강 세팅 1분대.바로 가능: 마스터 콘솔 → 👹 보스 → 보스 하나씩 체력 배율 → 🚀 정식 적용 (코드 수정 없이)
  2. 장 난이도 모델에 상한 넣기expStats·CHM·recCp 가 레벨을 min(150, 8n−1), 계승을 min(2, …) 로 쓰게. 몹 체력·피해와 권장 전투력이 함께 현실로 내려온다. 또는 반대로 레벨 상한(150)이나 계승 횟수(2)를 늘려 모델에 맞춘다.코드 수정 (test 에서 먼저)
  3. 치명타 확률 넘침 해결하의 기본 능력치를 치명타 피해로 바꾸거나, 100% 넘는 치명타를 1%p 당 치명타 피해 +0.5~1% 로 바꾼다(지금 100%p 당 +1%). 그러면 치명타 확률 잠재·옵션·하의 강화가 다시 의미를 가진다.코드 수정
  4. 견갑·신발 기본 능력치 키우기보스 피해·방어 무시가 강화 1단계에 0.085%/L 라 체감 0. 3~5배로 올리거나 다른 능력치로.코드 수정 (SLOT_INFO.per)
  5. 재사용 대기 감소 잠재 손보기딜의 약 80% 가 평타라 한 줄 +1.7%. 평타 공격 속도에도 일부 붙게 하거나 범위를 올린다.코드 수정
  6. 레벨 150 이후 성장 보상19장부터 경험치가 스펙에 안 들어간다. 만렙 뒤 경험치를 특성 포인트·재료로 바꿔 주거나, 경험치 획득량 잠재를 만렙 뒤 다른 효과로.기획 결정 필요
  7. 전투력·권장 전투력 고치기전투력에 각성(×1.3)과 보스 피해(지금 ÷4)를 제대로 넣고, 권장 전투력은 레벨 150·계승 2회 상한 기준으로. 지금은 숫자가 플레이어를 헷갈리게 한다.코드 수정 (calcStats 의 cp, recCp)
  8. 특성 균형Z 특성의 단계당 효과를 낮추거나(예 +5% → +3%), X·C·A·S·D 특성을 올려 다른 선택도 의미 있게. 마스터 콘솔 ⚔ 전투 → 특성 탭에서 신규형 단계 피해·15단계 보너스를 바로 바꿔 볼 수 있다(직업·스킬 구분 없이 공통).일부 바로 가능 (마스터 콘솔) · 스킬별로 다르게 하려면 코드 수정

측정 방법

게임 코드: 정식 index.html (261125-1500). calcStats·presetGear·slotLeq·makeItem·makeRing·spawnBoss 를 헤드리스 크로뮴에서 그대로 호출.
효율 표: 장마다 기대 캐릭터 하나를 만들고 수단 하나씩만 바꿔 % 변화. 잠재는 레전드 평균값 한 줄을 무기 칸에 넣어 계산. 특성·재사용 대기 감소는 허수아비로 잰 스킬 비중으로 추정.
처치 시간: test 서버 허수아비(방어력 = 보스 방어력), 테론, 게임 속도 3배로 90초, X·C·A·S·D + 평타 자동 조작. 보스 체력은 실제 spawnBoss 값(보스 배율 적용 후).
안 넣은 것: 축복의 제단·파티 보너스·이벤트 배율·마스터 콘솔 수치(모두 기본값).
